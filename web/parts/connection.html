The switch shows the mode in use; changing it and the buttons come in a later story — today the network is set in updown's settings (BIND).
How to connect the phone

📶 Hotspot over Wi-Fi

  1. iPhone: Settings › Personal Hotspot › on
  2. this PC: Wi-Fi › join the iPhone's network
  3. this block turns green when the phone opens a page

🔌 Hotspot over USB

  1. iPhone: Personal Hotspot › on
  2. plug the cable in, tap "Trust" on the phone
  3. this PC uses it by itself (no photo import needed)

🏠 Same Wi-Fi

  1. only when updown uses any network (BIND=auto)
  2. PC and phone on the same router
  3. only on your own Wi-Fi

Not possible: Bluetooth file push (iPhones accept files over Bluetooth only via AirDrop). Joining a Wi-Fi or switching on the hotspot is done on the PC / the phone — updown cannot do it for you.
